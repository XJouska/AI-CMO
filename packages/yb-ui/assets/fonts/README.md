# Team Font Bundle

The internal skill bundle includes the four original font files listed in
`manifest.json`. Do not strip them from the package. Validate size and SHA-256
before use; a missing or altered file makes this bundle incomplete.

First check whether the exact family/style is available to the current Figma MCP
account in the target file. Reuse team/organization fonts when available.
Otherwise use these bundled files for the current account's official font upload,
subject to actual upload rights and organization policy. Local OS installation
alone does not make a font available to cloud MCP.

Re-run font enumeration, exact load, and a minimal text-write probe after upload.
Until successful, affected text edits remain blocked. Never replace the typeface.
Personal-account configuration does not configure the whole team.

These bytes are supplied by the user for their internal workflow. The checksum
manifest is not a font license or permission for public redistribution, web
deployment, or platform upload. Preserve existing license files when supplied;
do not invent rights declarations.
