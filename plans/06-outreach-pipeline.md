# 06 · 触达与跟进

> 目标：让商机变成询盘和订单。为每条商机生成个性化开发信，记录跟进状态，提醒下一步，并用结果反过来训练商机评分。
> 结束状态：业务员可以在手机上完成「看商机 → 生成开发信 → 确认发送 → 记录回复 → 推进状态」，每周收到效果周报。

---

## 1. 范围

**包含**：开发信生成、发信方式、跟进状态流转、提醒、跟进记录、周报、结果回流评分。
**不包含**：全自动批量群发、营销邮件序列自动化（首版不做，避免垃圾邮件和品牌风险）。

---

## 2. 跟进状态

```
新商机 → 已查看 → 已联系 → 已回复 → 已询价 → 已报价 → 打样中 → 已成交
                                  ↘ 无效 / 已放弃（任一阶段可进入，需选原因）
```

状态变化写入跟进记录，并作为评分校准数据（例如「已回复」及以后视为正样本）。

---

## 3. 数据模型

| 表 | 关键字段 |
|---|---|
| `lead_pipeline` | lead_id, company_id, stage, owner_user_id, next_action, next_action_at, lost_reason, deal_value, currency, updated_at |
| `lead_activities` | id, lead_id, user_id, kind(`note` / `email_draft` / `email_sent` / `reply` / `call` / `stage_change`), content(JSON), created_at |
| `outreach_drafts` | id, lead_id, channel(`email` / `linkedin_message` / `whatsapp`), language, subject, body, version, status(`draft` / `approved` / `sent`) |
| `mail_accounts` | id, company_id, provider(`smtp` / `gmail` / `outlook`), from_address, encrypted_credentials, daily_limit, verified |
| `email_suppressions` | company_id, email, reason |

## 4. 后端任务

### 4.1 开发信生成

1. 输入：商机详情、买家信息、企业档案、匹配产品、官网链接、用户签名。
2. 输出：主题 + 正文（英文，或目标市场语言），并提供 3 种语气（简洁 / 专业 / 热情）。
3. 约束：不得编造合作客户、证书、价格；必须引用商机中的具体需求；附官网和产品链接；长度控制在 120–200 词。
4. 支持在对话中修改：「再短一点」「强调我们有 CE 认证」。

### 4.2 发送方式（两档）

| 方式 | 说明 | 首版 |
|---|---|---|
| 复制 / 唤起邮件客户端 | 生成 `mailto:` 链接或一键复制，用户用自己的邮箱发送 | **必做** |
| 绑定企业邮箱发送 | SMTP 或 OAuth 绑定；系统代发并记录 | 可选，试点后再做 |

绑定邮箱时：

- 凭据使用应用级密钥加密存储（密钥来自环境变量），接口永不返回明文
- SMTP 服务器地址同样经过 SSRF 校验（不允许指向内网）
- 每个邮箱每日发送上限；每封邮件**必须由用户点击确认**才发送
- 支持退订链接与屏蔽名单（`email_suppressions`），尊重 GDPR / CAN-SPAM 等要求
- 发送前检查 SPF / DKIM 配置并提示

### 4.3 提醒

- 设置下一步动作和时间；到期生成站内通知（计划 07 接入微信 / 邮件推送）
- 截止日期临近的招标（剩余 7 天、3 天）自动提醒

### 4.4 周报

- 每周一生成：新增商机数、有效率、已联系数、回复率、询价数、成交数、官网访问与询盘、下周建议重点
- 在助手中以结构化消息推送（`Markdown` H3 + Table + OL），同时可在「我的」中查看历史周报

### 4.5 结果回流

- 用户反馈和跟进阶段作为标签写入评测数据集
- 每周统计各数据源、各类型商机的转化率，用于调整监控和评分权重（运营后台可见）

### 4.6 助手工具

| 工具 | 是否需要确认 |
|---|---|
| `outreach.draft(lead_id, tone, language)` | 否 |
| `outreach.revise(draft_id, instruction)` | 否 |
| `outreach.send(draft_id)` | **是** |
| `pipeline.update_stage(lead_id, stage, note)` | 否 |
| `pipeline.list_due` | 否（「今天该跟进哪些？」） |
| `report.weekly` | 否 |

## 5. 前端任务

### 5.1 商机详情页增强

- 顶部增加跟进阶段 `Status` 与「推进」按钮（`ActionSheet` 选择下一阶段；选择「无效 / 放弃」需选原因）
- 「跟进记录」时间线：笔记、已发邮件、回复、阶段变化
- 「添加记录」：`BottomSheet` 内 `FormFields`，可选类型

### 5.2 开发信编辑页

```
NavBar（标题「开发信」，右侧「重新生成」）
├── 语气 Tab：简洁 / 专业 / 热情
├── 收件人（买家公开邮箱，可编辑）
├── 主题（FormSingleLine）
├── 正文（FormFields，多行）
├── 「让 AI 修改」输入
└── 底部按钮：「复制」「用邮箱打开」「确认发送」（绑定邮箱后显示）
```

- 确认发送使用 `Dialog`，展示收件人和主题
- 发送成功 `Toast`，自动把商机推进到「已联系」

### 5.3 待办视图

- 助手欢迎页建议「今天有 3 条商机需要跟进」

### 5.4 周报页

- 「我的」→「效果周报」：周报列表 → 详情（结构化展示，可分享为图片，计划 07 实现分享）

## 6. 验收标准

- [ ] 从商机一键生成开发信，内容引用具体需求，无编造事实
- [ ] 复制和 `mailto:` 方式可用；绑定邮箱后发送需二次确认，且受每日上限约束
- [ ] 邮箱凭据加密存储，接口和日志中不出现明文
- [ ] 阶段流转与跟进记录正确，状态变化计入评分数据
- [ ] 截止日期提醒和下一步提醒按时产生
- [ ] 每周一自动生成周报并在助手中推送
- [ ] 全部页面状态完成截图检查
