# 07 · 运营后台、计费与上线

> 目标：支撑「代运营服务 + 自动化交付」的商业模式，让我方运营团队能高效服务多家客户；完成套餐计费、通知、可观测性、安全审查和生产部署。
> 结束状态：可以正式签约两家付费试点客户，并稳定交付。

---

## 1. 范围

**包含**：运营工作台、商机复核、客户健康度、套餐与用量、支付、通知推送、数据合规、可观测性、性能与包体优化、安全审查、生产部署与备份。

---

## 2. 运营工作台（staff 可见）

入口：「我的」Tab 中，`is_staff` 用户可见「运营工作台」分组。界面仍使用 yb-ui；数据密集的批量操作页可在桌面宽度下自适应为双栏。

| 功能 | 说明 |
|---|---|
| 客户列表 | 企业名、套餐、档案完整度、官网状态、本周商机数、有效率、最近活跃 |
| 复核队列 | 待复核商机，支持快速通过 / 驳回 / 编辑摘要；键盘快捷键（桌面） |
| 代客操作 | 以 `operator` 角色进入客户企业，所有操作记录审计日志并标记「运营代操作」 |
| 数据源监控 | 各连接器成功率、耗时、封禁情况、产出有效率 |
| 成本看板 | 各企业 LLM token、搜索 API 调用、抓取次数、估算成本 |
| 评测集管理 | 标注样本、跑评测、查看指标趋势 |

审计日志表：`audit_logs(id, actor_user_id, company_id, action, target_type, target_id, detail, ip_hash, created_at)`，敏感操作（权限变更、数据导出、代客操作、发布官网、发送邮件）全部记录。

## 3. 套餐与计费

### 3.1 套餐（与创业计划中的定价一致，可配置）

| 套餐 | 内容 | 计费 |
|---|---|---|
| 建站版 | 官网生成与托管、询盘回流 | 一次性实施费 + 年托管费 |
| 获客版 | 建站版 + 商机监控（每月商机上限）+ 开发信 | 月费 |
| 代运营版 | 获客版 + 运营人工复核与代跟进 | 月费（较高） |

### 3.2 实现

- 表：`plans`、`subscriptions`、`usage_records`（按类型记录：商机数、LLM token、监控运行次数、官网数）、`invoices`
- 用量限制在服务层统一检查，超限时助手和界面给出明确提示与升级入口
- 支付：首版以**对公转账 + 后台手工开通**为主（符合 B2B 签约习惯）；在线支付（支付宝 / 微信支付）作为可选项，回调必须验签、幂等处理、金额以服务端订单为准
- 「我的」→「套餐与用量」：当前套餐、有效期、本月用量进度、续费 / 升级联系入口

## 4. 通知

| 渠道 | 内容 |
|---|---|
| 站内通知 | 新商机、新询盘、跟进提醒、周报、系统消息（`Notification` 组件） |
| 邮件 | 每日商机摘要、周报 |
| 企业微信 / 微信服务号 | 新询盘、高分商机即时提醒（需配置，可选） |

- 用户可在设置中分别开关（`ListTrailingSwitch`）
- 通知任务在 worker 中执行，失败重试并记录

## 5. 数据合规

- 隐私政策与用户协议页面
- 联系人数据：记录来源和采集时间；提供删除请求处理接口（运营后台处理）
- 企业数据导出（JSON / CSV）与注销删除
- 日志保留期限与脱敏；数据库备份加密

---

## 6. 可观测性与稳定性

- 结构化日志集中收集；关键指标：接口错误率、SSE 中断率、worker 队列积压、连接器失败率、LLM 延迟与成本
- 错误追踪（Sentry 或同类，自托管优先）
- 健康检查与告警：API、worker、数据库、证书到期
- 数据库每日备份 + 每周恢复演练

---

## 7. 前端质量收尾

- Dark 主题全页面验收
- 包体优化：按实际使用清单裁剪 `packages/yb-ui/public` 中的图标与图片；路由级代码分割
- 移动端性能：首屏可交互 < 3 秒（4G 网络模拟）
- 可访问性：按钮可读标签、焦点顺序、弹层焦点恢复（设计包 `DeviceOverlays` 已提供基础）
- 视觉回归：Playwright 对所有页面关键状态截图，作为后续改动的基线
- 交互走查清单：对照设计包 `interaction-patterns.md` 逐条检查命中的模式

---

## 8. 安全审查（上线前必须完成）

1. 使用安全审查子代理对全部改动做一次完整审查。
2. 检查清单：
   - [ ] 所有接口的认证、企业归属、角色校验（自动化测试覆盖率 100%）
   - [ ] SSRF：抓取、官网健康检查、买家补全、SMTP、Webhook 全部经过 `safe_fetch`
   - [ ] XSS：应用、官网模板、询盘、LLM 输出、开发信预览
   - [ ] SQL 注入：无原生拼接 SQL
   - [ ] 无 shell 调用；无 `pickle` / 不安全 YAML
   - [ ] 密钥只在环境变量；仓库与镜像中无明文
   - [ ] 公开接口限流；登录防爆破
   - [ ] 依赖漏洞扫描无高危
   - [ ] 安全响应头与 CSP 生效
   - [ ] 提示词注入：外部内容无法触发有副作用的工具
3. 修复后复测并记录到 `docs/security-review.md`。

---

## 9. 生产部署

- 服务器：`api`（可多实例）、`worker`（含浏览器）、`web`、`sites`、`db`
- 反向代理：Caddy 或 Nginx + certbot，支持平台泛域名和客户自定义域名自动签发证书
- 数据库只在内网可访问；所有容器非 root；镜像固定版本
- 发布流程：构建镜像 → 迁移数据库 → 滚动重启；保留回滚脚本
- 运维手册 `docs/runbook.md`：部署、回滚、备份恢复、证书、常见故障
